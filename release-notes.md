# AltStack Social 1.2.0

A global AltStack account: country badges follow your selected country or region, editable from desktop account settings. Human confirmation replaces American membership confirmation. Browser account approval provides the same signup, country choice, CAPTCHA and recovery codes as the website.

Six native packages: Windows x64 and ARM64, macOS Intel and Apple Silicon, Linux x64 and ARM64. Uses the working platform origin until the new root domain is active.

AltStack Social 1.1.2 - Early access

Rebuilt native Qt apps with the official AltStack logo, silver interface, shared AltStack accounts, feeds, messages, communities and account tools.

Windows x64 and ARM64 portable ZIPs; macOS Intel and Apple Silicon DMGs; Linux x64 and ARM64 TAR.GZ packages. Extract the complete archive before launching. Linux includes install-linux.sh. Python is bundled.

Requires Windows 11, macOS 14+, or Ubuntu 24.04+ with a desktop keyring. Builds are unsigned; macOS apps are ad-hoc signed, not Developer ID signed or notarized. No automatic updater. SHA-256 sidecars accompany every package.

Uses the working AltStack account service at www.amerika.social during migration. It automatically chooses altstack.org after HTTPS works and the server announces that canonical origin. No session credentials are sent during domain discovery.
