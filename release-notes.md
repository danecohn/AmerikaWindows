AltStack Social 1.1.0 � Early access

Rebuilt native Qt apps with the official AltStack logo, silver interface, shared AltStack accounts, feeds, messages, communities and account tools.

Windows x64 and ARM64 portable ZIPs; macOS Intel and Apple Silicon DMGs; Linux x64 and ARM64 TAR.GZ packages. Extract the complete archive before launching. Linux includes install-linux.sh. Python is bundled.

Requires Windows 11, macOS 14+, or Ubuntu 24.04+ with a desktop keyring and Qt system libraries. Builds are unsigned; macOS apps are ad-hoc signed, not Developer ID signed or notarized. No automatic updater. SHA-256 sidecars accompany every package.

During the domain transition the application connects to the existing production API at www.amerika.social. This is the same AltStack account service and will remain available during migration.
